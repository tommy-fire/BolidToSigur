# v3.2 — файл между двумя этапами · 30.09.2026

Одна программа, две вкладки. SQL-выгрузка создаёт единый .bolid; вкладка подготовки Sigur открывает его без SQL, включая на другом ПК. В ZIP-контейнере только явный список исходных файлов, проверка и фото; результаты прошлых импортов и произвольные локальные файлы не включаются.

Извлечённые фото кэшируются с привязкой к исходному полю и хешу JPEG: локальные пути прежнего ПК повторно не требуются. На переносимой копии автоматическое чтение внешних путей запрещено. Исходные pList/pMark сохраняются без потери ведущих нулей и связей.

Открытие создаёт новую рабочую папку. «Сохранить проверку в .bolid» сохраняет операторские разрешения, контрольные номера, профили, выбор полей дат и режим кадровых полей. Диагностический режим нескольких карт не переносится. Хеши проверяют целостность, не аутентичность; доверять можно только собственной/проверенной выгрузке. Архив не зашифрован.

33 офлайн-теста проходят. Новые проверки: round-trip .bolid→XLS без SQL с leading-zero W34, владельцами и точным временем; фото из локального файла после удаления источника и повторной упаковки; повреждения/версии/дубликаты путей/ссылки/выход за каталог/лимиты/очистка временных файлов; отказ при подмене владельца; атомарная запись поверх старого контейнера.

Дополнительно реальный цикл Tk под Linux/Xvfb: открытие, редактирование наблюдаемого номера, разрешение карты, выбор дат, сохранение .bolid и создание XLS. Второй сценарий проходит через первую вкладку с mock discover/snapshot. Проверена видимость основных кнопок при 1180×820 и 880×680. Это НЕ испытание SQL, Windows, Sigur или физических проходов.

Ограничения v3.1 сохраняются: физическая калибровка W34, проверка статусов, ограничения нескольких карт со сроками, только тестовая целевая база. Режим Турникет — 24/7 назначается отдельно в Sigur, без комнаты охраны. Запускатель для офлайн-пути не требует SQL-драйвер; полный набор зависимостей оставлен отдельным requirements-safe.txt.

Файлы с реальными данными (*.bolid, project_*, snapshot_*, result_*) исключены из Git. Лёгкая поставка содержит только папку программы с памяткой, не дублирует большие официальные PDF.
