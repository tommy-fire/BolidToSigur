# Итог v3.1 · 29.09.2026

Согласованный состав кадров, отдельные поля/примечание, обе даты с точным временем, явный выбор полей начала/окончания в GUI, CSV сверки каждой карты, диагностический режим нескольких карт со сроками. Режим Турникет — 24/7 задаётся в Sigur отдельно, без комнаты охраны.

25 офлайн-тестов проходят. Все исходники Python компилируются. BAT проверен как CRLF, запуск остаётся через START_SAFE.bat. Реального запуска GUI под Windows, SQL пользователя, импорта и проходов нет; это не акт приёмки.

Документация Sigur от 23.09.2026 неоднозначна для сроков строк продолжения. Оставлен консервативный запрет по умолчанию на всю группу нескольких карт со сроками: нельзя без проверки считать, что остальные карты не унаследуют дату первой. Произвольно выбирать одну «главную» карту также не стали. Для диагностики отдельное имя XLS, лист ДИАГНОСТИКА и подтверждение в GUI. Исходные записи не теряются; список исключений и сверки сохраняется.

Неподписанные даты в примечании не считаются автоматически датой рождения. Это может потребовать настройки по реальному примеру пользователя. Фото, паспорт и адрес не считаются проверенными только по факту создания файла; предупреждения перед импортом обязательны.

Сроки: локальная дата/время до секунды. Часовой пояс, доли секунды, некорректный порядок границ отклоняются. Пустые границы требуют решения оператора; GUI предупреждает о последствиях. Блокировки из исходной базы автоматически не интерпретируются.
