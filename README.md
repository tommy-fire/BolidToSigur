# BolidToSigur — перенос СКУД «Орион Про» (Болид E510) → Sigur

Проект: полный переезд с Болид на Sigur E510 — инструкция по монтажу и
настройке + инструменты переноса сотрудников и карт из базы «Орион Про».

## Что в репозитории

- `ИНСТРУКЦИЯ/` — основная папка:
  - текстовые блоки `00…16` — пошаговая инструкция (монтаж, подключение,
    настройка E510 и Sigur, турникет, считыватели, закупка, перенос);
  - `.png` — схемы подключения к каждому блоку;
  - `ПОЛНАЯ_ИНСТРУКЦИЯ_Sigur_E510.pdf` — всё одним документом;
  - программы: `Выгрузка_из_Болид.pyw`, `Выгрузка_из_резервной_копии.pyw`,
    `Миграция_Болид_Sigur.pyw` (все v.01), `Поиск_базы_Болид.py`,
    `Конвертер_Орион_в_Sigur.py`, `Шаблон_импорта_карточек.xls`
    и `.bat`-запускатели;
  - `16_Шпаргалка_импорта_Sigur.txt` — краткая инструкция по импорту;
  - `13…15` блоки — описание переноса карточек и программ.
- `_svg/` — исходники схем; `_build_scripts/` — сборка PDF;
  `skud-sigur-e510/` — HTML-версия руководства.

## Ключевое в переносе карт (W34)

Код карты в базе Болид хранится перевёрнутым по байтам, вместо байта `00` —
вставки-экраны (`FE01` / `01FE01`), в конце — служебный хвост `01`.
Номер карты Sigur (W34) = **8 hex-знаков до `01` в конце** кода АБД.
Программа «Миграция» делает это автоматически (функция `w34_theory`),
сверка по известной карте — через поле «4. Номер своей карты».

Старые карты (плотные, с прорезью) номера в базе не содержат — программа
помечает их «код читается неоднозначно», добавляются вручную захватом.
