# BolidToSigur · v3.3

## Простой запуск — две кнопки

1. Создать `C:\BolidToSigur`, распаковать туда все файлы лёгкого архива программы.
2. Запустить **ЗАПУСК.bat**, ввести логин и пароль.
3. **«1. Найти базу и выгрузить»** → файл `.bolid` рядом с программой.
4. **«2. Выбрать выгрузку и создать файл Sigur»** → выбрать файл → результат рядом.

Без вкладок, галочек, профилей и выбора дат. Выбор рабочей базы запрашивается только при нескольких найденных базах. Автопоиск сохранён; шаг 2 не обращается к SQL. [Короткая инструкция](01_ПЕРЕНОС.md).

## Граница готовности — прочитать

**Простой режим пока НЕ создаёт рабочие назначения карт.** Он выдаёт XLS кадров **без номеров пропусков** и отдельные CSV для сверки кодов/владельцев/дат. Мы не имеем реальных контрольных считываний и подтверждённых статусов/полей вашей базы. Автоматическое назначение предполагаемых W34 могло бы выдать доступ чужой или заблокированной карте.

Номера в отчёте явно помечены как неподтверждённые; статусы не угадываются; никакие поля Approve/ObservedW34 не заполняются фиктивно. Простота UI не означает готовность массового переноса. Нужна первичная проверка на объекте. Этот недостаток не скрывается за сообщением «Готово».

Прежний проверочный интерфейс сохранён **для специалиста** в `ИНСТРУКЦИЯ/Проверка_специалиста.py`. Его правила W34/CRC/калибровки/владельцев/сроков не ослаблены. Техническая памятка: `audit/РАСШИРЕННАЯ_ПРОВЕРКА.md`.

## Состав

- `ИНСТРУКЦИЯ/` — программа и памятка. При скачивании всего репозитория запускайте `ИНСТРУКЦИЯ/ЗАПУСК.bat`; файлы будут рядом с ним.
- `research/` — официальные руководства и источники.
- `audit/` — воспроизводимые тесты и история изменений.
- [Подключение E510](02_ПОДКЛЮЧЕНИЕ.md) — ограничения неизвестного оборудования и аварийного выхода.

Согласованы ФИО, табельный номер, компания/отдел, должность, фото, дата рождения, паспорт/прописка, карты и обе границы срока. В простом режиме кадровые поля — в XLS, неподтверждённые карты/сроки — в отчёт. Тестовый родительский отдел добавляется к компании/подразделению. Права **Турникет — 24/7**, без комнаты охраны, задаются отдельно только после проверки.

Python 3.10+, Tkinter. `requirements-offline.txt` — для открытия файла и XLS, `requirements-safe.txt` — полный набор с pyodbc. Microsoft ODBC-драйвер SQL Server нужен только для SQL-выгрузки, устанавливается отдельно. `.bolid` не зашифрован; реальные выгрузки не хранить в Git.

## Проверки

```bash
python -m pip install xlwt xlrd Pillow
python -m unittest discover -s audit -p 'test_*.py' -v
# Linux, если установлен Xvfb:
xvfb-run -a python audit/smoke_simple.py
```

39 офлайн-тестов, отдельная проверка простого GUI с синтетической базой-заглушкой. Реальный SQL пользователя, Windows, Sigur и физические проходы не испытаны. Результаты — `audit/test_results_v3_3.txt` и `audit/gui_smoke_v3_3.txt`.
