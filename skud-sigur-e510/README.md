## Система в одном абзаце

Один контроллер **Sigur E510** управляет двумя точками:

1. **Дверь** (1-й этап): магнитный замок, считыватель на входе, считыватель на выходе,
   кнопка выхода внутри, геркон (датчик положения двери).
2. **Турникет Smartec** (2-й этап): считыватели на вход/выход, линия «Разблокировка» на
   управляющий вход платы турникета, кнопка с тремя клавишами, датчики прохода (опционально).

**Аварийное открытие** (зелёная кнопка Smartec + дубль-кнопка) подключаются к двухпроводному
шлейфу аварийной разблокировки E510 (клеммы F+/F−). Нажатие любой из кнопок рвёт шлейф —
контроллер мгновенно открывает дверь И турникет (режим «пожар»), не завися от ПО и сервера.

Питание 12 В — от **РИП-12** с АКБ (рекомендован производителем E510), 220 В — на сам турникет.
Сервер Sigur уже установлен — останется только настроить точки доступа и прописать карты.

## Схема (кратко)

```
[Щиток B10] → [РИП-12 12В+АКБ] → [Sigur E510] ──Ethernet── [Коммутатор] → [ПК: сервер Sigur]
                                      │ точка 1 «Дверь»          │ точка 2 «Турникет»
                                      ├─ PORT1/PORT2 — считыватели├─ PORT3/PORT4 — считыватели
                                      ├─ K1 (реле) — магнитный замок├─ K2 (реле) — вход «Разблокировка»
                                      ├─ D1 — геркон двери         ├─ D2 — датчики прохода (опц.)
                                      ├─ D3 — кнопка выхода        ├─ D4/D5/D6 — кнопка с 3 клавишами
                                      └─ F+/F− — шлейф аварийки:
                                          зелёная кнопка (НЗ) + реле от дубль-кнопки (НЗ)
```

## Что прислать фото (чтобы я уточнил детали под ваши приборы)

1. Табличка/подпись контактов **зелёной кнопки** Smartec (модель, типа ST-ER125D-GN).
2. Сторона с контактами **дубль-кнопки** (2 контакта + подсветка).
3. **Считыватели** — маркировка (подтвердить Wiegand-26).
4. **Магнитный замок** — табличка (напряжение, ток, габарит).
5. **РИП-12** — табличка (исполнение: 2А / 3А / 5А).
6. На 2-м этапе: **фото клеммной колодки платы турникета** (из люка) — выдам точную схему
   по названиям клемм, и фото **кнопки с тремя клавишами** (что на них написано).

## Безопасность

- Работы с **220 В** (клеммы L/N/PE на РИП-12 и турникете) — только с отключённым
  автоматом и проверкой отсутствие напряжения. Если опыта в электромонтаже нет — эту
  часть лучше сделать с электриком; всё 12-вольтовые — безопасно, можно самому.
- Все 12-вольтовые подключения — при отключённом РИП-12 от сети.
- Пошаговый чек-лист с контрольными точками — в главном документе (разделы 3.6 и 4.5).
