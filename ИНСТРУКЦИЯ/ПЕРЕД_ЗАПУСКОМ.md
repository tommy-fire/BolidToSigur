# Болид → Sigur · v3.5 — сотрудники и карты

**v3.5: в примечании только дата рождения. Сотрудники без карт включены в общий XLS.** Пользователь подтвердил успешный перенос и работу v3.4 на своём объекте. Алгоритм карт и сроков в v3.5 не менялся. Автоматический перенос блокировок по-прежнему не реализован; общая работоспособность на всех конфигурациях этим не подтверждается.

В примечании: `Дата рождения: ДД.ММ.ГГГГ`. Если достоверно выделить дату не удалось — пусто. Паспорт, прописка, исходные заметки и служебные предупреждения в примечание не добавляются. Паспорт и прописка остаются отдельными колонками, как прежде; их можно не сопоставлять, если не нужны.

## 1. Обновить программу

1. Закрой старую программу.
2. Распакуй содержимое нового ZIP в `C:\BolidToSigur`, согласись заменить файлы программы. Старую выгрузку `.bolid` не удаляй.
3. Запусти **`ЗАПУСК.bat`**. В заголовке окна должно быть **v3.5**.
4. Если выгрузка `.bolid` уже есть — сразу нажми **кнопку 2** и выбери её. Новое подключение к Болид не требуется. Старый XLS выбирать нельзя.
5. Если выгрузки ещё нет — введи логин/пароль и нажми **кнопку 1**. База ищется автоматически; файл сохранится рядом с программой. Затем нажми кнопку 2.

Никаких профилей, галочек и выбора полей в программе нет. Если найдены несколько баз, нужно выбрать рабочую. Прежние выгрузки не перезаписываются.

## 2. Открыть результат

В новой папке `Для_Sigur_дата` появится **`ПРОБНЫЙ_ПОЛНЫЙ_Импорт_Sigur.xls`**.

Он содержит ФИО, табельный номер, компанию/отдел, должность, фото, дату рождения, паспорт, прописку, распознанные кандидаты номеров W34 и найденные начало/окончание действия каждой карты с временем. Сотрудники без карт тоже включены. Дополнительные карты записаны следующими строками без повторения ФИО. Телефон/email в импорт не включены.

Программа покажет **число сотрудников (в том числе без карт), карт и исключений**, а также сколько карт осталось без дат. Нераспознанные номера, конфликтующие владельцы и недопустимые даты не заменяются догадками. Причины — в `Исключения.csv`. Если есть исключения, импортируется не всё. Если однозначных сотрудников нет, XLS не создаётся и программа об этом сообщает.

## 3. Импортировать в Sigur

**Только отдельная пустая тестовая база. Не поверх рабочей. Пока не назначать права и общий режим 24/7.** Сам файл не блокирует доступ, если импортировать его не туда. Он включает также неактивные/заблокированные исходные записи без переноса их блокировок.

Персонал → Импорт из таблицы MS Excel → выбрать **новый** XLS.

**Сопоставь поля заново по названиям**, не оставляй номера колонок от прежнего файла:

| Поле в Sigur | Столбец XLS |
|---|---|
| ФИО | ФИО |
| Отдел | Отдел |
| Должность | Должность |
| Табельный номер | Табельный номер |
| Номер пропуска | Номер пропуска |
| Начало действия пропуска | Начало действия пропуска |
| Окончание действия пропуска | Окончание действия пропуска |
| Тип записи | Тип записи — в нём «Сотрудник» |
| Имя файла фотографии | Имя файла фотографии |
| Примечание | Примечание |
| **Тип пропуска** | **НЕ включать, НЕ сопоставлять** |

В новом XLS **нет колонки «Тип пропуска»**: по руководству Sigur при её отсутствии используется «Карта». Не путать с «Тип записи»! Не выбирать вместо неё «Сотрудник», «W34», номер карты или пустую колонку. Это устраняет источник несовместимости пустого типа, но точная причина прежней ошибки без вашего файла/скриншота не установлена.

**Примечание** сопоставляй только с колонкой **Примечание** — там теперь одна дата рождения. Отдельные колонки даты рождения, паспорта и прописки можно сопоставить с дополнительными полями Sigur, если они нужны. Не сопоставляй паспорт или прописку с Примечанием. «Орион ID» — только для сверки, не ID Sigur и не номер пропуска. Фото держи рядом с XLS в папке `Фотографии`.

### Если сотрудники уже перенесены

Создание нового XLS не меняет старые примечания в Sigur. Перед обновлением сохрани резервную копию базы Sigur. Для очистки уже перенесённых примечаний при импорте выбери идентификацию **Тип записи / ФИО / Отдел** и обновление **только Примечания**; не включай номера карт, сроки, режимы и прочие поля, которые могли быть изменены в Sigur. Сначала проверь на копии базы, что сотрудник обновился без дубля и что пустое примечание очищает старое. Поведение очистки пустой ячейкой зависит от версии и настроек импорта и нами не проверено. Если старый текст остался — не включай перезапись карт ради очистки примечаний.

Сотрудники без ключей присутствуют в общем XLS полноценными строками с ФИО, отделом, должностью, табельным номером, фото и датой рождения при наличии. У них пустые поля карты и её сроков. Это не строки продолжения дополнительных карт: в строке продолжения ФИО пустое. Если исходная карточка неоднозначна, причина остаётся в `Сотрудники_исключения.csv`; отсутствие ключа само по себе не исключает человека.

## Если сроки опять пустые или есть ошибка

- Пришли **`ДИАГНОСТИКА_СТРУКТУРЫ.json`** из папки результата. В нём названия/типы полей и количества, **без значений строк** — без ФИО, паспортов, кодов карт и паролей. Он поможет настроить поля дат именно вашей базы.
- При ошибке импорта пришли скрин сопоставления колонок и сообщение целиком, с номером строки; укажи версию Sigur из «Справка → О программе». Замажь персональные данные на скрине, если они видны.
- **Пустой конец может стать бессрочностью, пустое начало — временем импорта.** До выяснения не назначать доступ. Программа не подставляет сегодняшнюю дату или условный 2099 год.

## Перед рабочим переключением

Успешное чтение XLS не доказывает совпадение физической карты. Проверить несколько реальных номеров на считывателе, владельцев, даты со временем (также вторую и последующие карты), фото и исходные блокировки. Не отключать Болид до проверки. Рабочая схема остаётся прежней: турникет — действующим сотрудникам с проверенными картами, 24/7; комната охраны отдельно. Индивидуальные сроки/блокировки нельзя отменять общим режимом.

## Установка, если это первый запуск

Windows, Python 3.10+ с Tkinter. Запускатель устанавливает Python-библиотеки при необходимости (нужен интернет). Для кнопки 1 также нужен Microsoft ODBC-драйвер SQL Server, он устанавливается отдельно. Для кнопки 2 ODBC не нужен. Все файлы должны лежать в доступной для записи папке, не внутри ZIP и не в Program Files.

`.bolid` не зашифрован; содержит персональные данные и коды карт. Храни защищённо, не загружай в GitHub. Это не `.bak` и не файл прямого импорта в Sigur. Исходная SQL-база только читается. `Служебные` содержит исходники для диагностики. Все исходные ключи в результате сохранены также в `Данные_всех_ключей.csv`.
