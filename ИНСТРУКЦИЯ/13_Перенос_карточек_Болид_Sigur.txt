------------------------------------------------------------------------------------
ШАГ 1. ЭКСПОРТ ИЗ «ОРИОН ПРО»

 Путь 1 — Мастер импорта/экспорта (НАЧНИТЕ С НЕГО, он проще)

   В папке установленного АРМ «Орион Про» лежит файл ImportWizard.exe.
   Это штатная утилита Болид, она умеет выгружать сотрудников и их
   идентификаторы в CSV.

   • Запустите ImportWizard.exe.
   • Выберите вашу базу данных, укажите операцию ЭКСПОРТ.
   • Сохраните CSV.

   Описание формата CSV лежит там же, на вашем компьютере:
     папка АРМ «Орион Про» → Doc → «015 - Мастер импорта и экспорта.pdf»
   Именно этот документ — истина для вашей версии. Обязательно загляните:
   состав полей между версиями «Орион Про» отличается.

   ПОЛЕЗНЫЙ ПРИЁМ: создайте в «Орион Про» двух-трёх тестовых сотрудников
   вручную, экспортируйте их и посмотрите, как выглядит файл. По образцу
   полученного файла сразу понятно, что и куда ложится.

 Путь 2 — напрямую из базы MS SQL (если утилита не даёт нужных полей)

   «Орион Про» хранит данные в MS SQL. Основные таблицы:
     pList  — люди: ФИО (Name, FirstName, MidName), табельный номер
     pMark  — ключи: CodeP (код карты), Owner — ссылка на pList.ID
     Company, AccessZone, GrAccess, AccessPoint — структура и доступ

   Посмотреть состав полей вашей версии:
     sp_columns pList;
     sp_columns pMark;

   Пример запроса (проверьте названия полей в своей версии!):
     SELECT
         p.TabNumber                              AS [Табельный номер],
         p.Name                                   AS [Фамилия],
         p.FirstName                              AS [Имя],
         p.MidName                                AS [Отчество],
         CAST(m.CodeP AS varbinary(max))          AS [Код ключа],
         m.Finish                                 AS [Срок действия]
     FROM pList p
     LEFT JOIN pMark m ON m.Owner = p.ID
     ORDER BY p.Name

   Результат сохраните в CSV (в «Управлении сервером» есть возможность
   выполнить SQL-запрос, либо используйте SQL Server Management Studio).

 ПРО КОДЫ КАРТ — ВАЖНО

   Поле CodeP выглядит как кракозябры. Это НЕ шифрование, это просто
   двоичные данные. Есть два способа получить из них нормальный код:
     • в SQL применять  CAST(CodeP AS varbinary) — тогда код виден как hex;
     • либо отдать сырое значение конвертеру — он попробует разобрать сам
       (перевернёт байты, уберёт служебные и возьмёт нужные).

ШАГ 2. КАК ПРЕОБРАЗУЕТСЯ КОД КАРТЫ

 Код карты из «Орион Про» — 8 байт. Правило взято из официальной статьи
 Sigur «Номера карт в СКУД и их конвертация»:

   1. Взять 4 ПРАВЫХ байта и отбросить последний.
   2. Получилось 3 байта. Левый — фасилити-код, перевести в десятичный вид.
   3. Два оставшихся — номер карты, перевести в десятичный вид.
   4. Записать через запятую:  фасилити,номер

 Пример (тот же, что в статье Sigur — сверяйтесь по нему):

   было   AE 00 1E 00 | 6E 14 F1 | 01
                        └─ берём эти 3 байта
   стало  6E → 110  (фасилити-код)
          14F1 → 5361  (номер карты)
   итог   110,05361     ← это и есть номер пропуска для Sigur

 Ещё примеры для самопроверки:
   76000B0050C9FE01  →  80,51710
   15003900347CFA01  →  52,31994
   E3000400AFCEFF01  →  175,52991
   C3004A00591D0301  →  89,07427

 Номер карты дополняется нулями до 5 знаков — это важно, ведущие нули
 значащие. Отсюда жёсткое требование: все ячейки таблицы должны быть
 в текстовом формате, иначе Excel съест нули.

 ФОРМАТЫ, КОТОРЫЕ ПОНИМАЕТ SIGUR:
   W26 ...... XXX,XXXXX   (фасилити-код и номер через запятую)
   W34 ...... 8 шестнадцатеричных знаков
   W42 ...... 10 шестнадцатеричных знаков
   W58 ...... 14 шестнадцатеричных знаков

ШАГ 3. ПРЕОБРАЗОВАНИЕ В ТАБЛИЦУ .xls

 Основной инструмент — ПРОГРАММА С ОКНОМ из БЛОКА 15 (Миграция_Болид_Sigur.pyw):
 выбираете файл, смотрите предпросмотр, жмёте одну кнопку. Для неё не нужна
 командная строка. Всё описанное ниже она делает сама.

 Для тех, кому удобнее командная строка, есть консольный конвертер
 Конвертер_Орион_в_Sigur.py. Оба инструмента делают одно и то же:

   • сам определяет кодировку файла (cp1251 / UTF-8 / cp866) и разделитель;
   • сам находит колонки по названиям (Фамилия / Имя / Отчество / Отдел /
     Должность / Код ключа / Табельный номер — и синонимы);
   • пересчитывает коды карт по правилу из шага 2;
   • склеивает ФИО, собирает иерархию отделов;
   • группирует несколько карт одного сотрудника (до 5 штук — так требует
     Sigur: первая карта в строке с ФИО, остальные в строках ниже, где
     заполнены только «Номер пропуска» и «Срок действия»);
   • программа с окном дополнительно ДОСТАЁТ ФОТОГРАФИИ из выгрузки
     (base64 / data-URI / hex — распознаёт сама по сигнатуре файла);
   • пишет готовый .xls с текстовым форматом всех ячеек.

 ЗАПУСК консольного варианта (нужен Python 3 и библиотека xlwt):
     pip install xlwt
     python3 Конвертер_Орион_в_Sigur.py выгрузка.csv

 НА ВЫХОДЕ файлы рядом с исходным:
   Импорт_для_Sigur.xls        — импортировать в Sigur
   Отчёт.txt                   — ЧИТАТЬ ОБЯЗАТЕЛЬНО
   Уровни_доступа.csv          — кто каким уровнем доступа пользовался
   Фото\                       — фотографии (если были в выгрузке)

 В отчёте смотрите три вещи:
   1. Нашёл ли скрипт колонки (если какая-то «НЕ НАЙДЕНА» — скажите мне,
      поправлю сопоставление).
   2. Сколько кодов распознано и сколько нет.
   3. Список строк, которые не разобрались, — с причиной.

ШАГ 4. ИМПОРТ В SIGUR

 1. БЭКАП. «Управление сервером» → «База данных» → «Экспорт базы»,
    сохранить ВНЕ папки программы. Серверный модуль остановится сам — это
    нормально, потом запустите его на вкладке «Состояние».

 2. ПРОБНАЯ ПАРТИЯ. Сначала импортируйте 5–10 человек из готового .xls.
    Приложите их карты к считывателю:
      • открылось — всё верно, импортируйте остальных;
      • «Неизвестный номер пропуска» — откройте событие, посмотрите код,
        который увидел Sigur, сравните с напечатанным на карте.

 3. ПОЛНЫЙ ИМПОРТ. Вкладка «Персонал» → «Импорт из таблицы MS Excel» →
    выбрать файл → сопоставить столбцы → «Импортировать».

 4. Опция «Перезаписывать пропуска» — при первом переносе лучше включить:
    пропуска сотрудника будут полностью взяты из файла.

------------------------------------------------------------------------------------
ЧТО ПЕРЕНОСИТСЯ, А ЧТО НЕТ — ЧЕСТНО

 ПЕРЕНОСИТСЯ АВТОМАТИЧЕСКИ:
   ФИО, табельный номер, должность, отдел (с вложенностью),
   номера карт (до 5 на человека), срок действия, примечание, телефон.

 НЕ ПЕРЕНОСИТСЯ АВТОМАТИЧЕСКИ — ЭТО ПРИДЁТСЯ СДЕЛАТЬ РУКАМИ:

   • Уровни доступа. В «Орион Про» это список точек доступа, в Sigur —
     свои механизмы. Это разные системы, прямого соответствия нет.
     Конвертер выгрузит файл «кто — какой уровень доступа», и по нему вы
     сможете воссоздать права в Sigur в разы быстрее, чем с нуля.
     Практический совет: сгруппируйте людей по уровням доступа, создайте
     в Sigur соответствующие группы и назначьте права группами, а не
     каждому сотруднику по отдельности.

   • Фотографии. Переносит программа из БЛОКА 15 — она достаёт их прямо
     из выгрузки, если они там есть, и складывает в папку «Фото» рядом с
     таблицей, с именами по табельному номеру. Если фото в выгрузке не
     оказалось — их добавляют в Sigur потом, руками.

   • Графики работы и PIN-коды — переносятся вручную.

ПРОВЕРКА ПОСЛЕ ИМПОРТА

 1. Вкладка «Персонал» — люди на месте, отделы построились.
 2. Карточка сотрудника — в поле «Пропуск» стоит номер вида 110,05361.
 3. Возьмите 5–10 РЕАЛЬНЫХ карт, приложите к считывателю. Главный тест.
 4. Сверьте количество: сотрудников в Sigur ≈ сотрудников в выгрузке.

ТИПОВЫЕ ОШИБКИ

 Ни одна карта не открывает дверь ...... Формат номера не совпадает.
   Приложите одну карту, посмотрите код в событии «Неизвестный номер
   пропуска» и сравните с тем, что в карточке сотрудника.

 Номера вида «0,00001» ................. Потеряны ведущие нули. Конвертер
   ставит текстовый формат, но проверьте, что файл не открывали и не
   пересохраняли в Excel после конвертации.

 «Номер пропуска» не подхватился ...... В окне импорта для этого поля не
   выбран нужный столбец.

 Сотрудники создались дублями ......... Разошлись ФИО или названия отделов
   (лишний пробел, разный регистр). Sigur считает их разными людьми.

 Скрипт не нашёл колонку с кодом ...... Пришлите мне первую строку файла
   (строку с названиями столбцов) — добавлю нужное название в сопоставление.

------------------------------------------------------------------------------------
ЧТО ПРИСЛАТЬ МНЕ, ЧТОБЫ ДОВЕСТИ ДО РАБОЧЕГО ВИДА

 1. Первую строку CSV-выгрузки — строку с названиями столбцов.
    Этого достаточно, чтобы точно настроить конвертер.
 2. Желательно — 3–5 строк с данными (номера можно затереть, важна
    структура: что в каком столбце).
 3. Версию «Орион Про» (меню «О помощь»).

Дальше я правлю скрипт под ваш формат и отдаю готовый .xls. Перенос
большого объёма — это всегда один-два круга подгонки, это нормально.
